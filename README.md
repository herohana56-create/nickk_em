## Размещение на Netlify Free

1. Войдите в свой аккаунт Netlify.
2. Add new project → Import an existing project → GitHub.
3. Выберите репозиторий `herohana56-create/nickk_em` и ветку `invites-launch4`.
4. Build command оставьте пустым. Publish directory: `.`.
5. Выберите Free и выполните Deploy. Проверьте публичный HTTPS-адрес без входа в кабинет.

Это исходники для нового размещения. Само наличие этой ветки не означает публикацию. GitHub Pages остаётся на отдельной ветке gh-pages.

Страницы: `/`, `/collection.html`, `/collection.html?demo=italy`, `/privacy.html`, `/consent.html`, `/terms.html`.

Локально: `python3 -m http.server 8766 --bind 127.0.0.1`. Сборка не требуется. Сохраняйте все локальные изображения, шрифты и их OFL-лицензии.
