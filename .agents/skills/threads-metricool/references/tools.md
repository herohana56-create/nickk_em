# Проверенные инструменты и примеры чтения

Проверено 2026-11-19. Сначала проверь доступные инструменты и их текущие схемы. Префиксы ниже отражают одну среду выполнения, а не обязательное глобальное имя.

| Назначение | Логическое имя | Имя в проверенной среде |
| --- | --- | --- |
| Проверка брендов и подключений | getBrandSettings | mcp__codex_apps__metricool_getbrandsettings |
| Список полей | getAnalyticsAvailableMetrics | mcp__codex_apps__metricool_getanalyticsavailablemetrics |
| Чтение аналитики и опубликованных постов | getAnalyticsDataByMetrics | mcp__codex_apps__metricool_getanalyticsdatabymetrics |
| Очередь будущих постов | getScheduledPosts | mcp__codex_apps__metricool_getscheduledposts |
| Планирование | createScheduledPost | mcp__codex_apps__metricool_createscheduledpost |
| Правка будущего поста | updateScheduledPost | mcp__codex_apps__metricool_updatescheduledpost |

## Сначала проверить подключение

Аргументы `getBrandSettings`:

```json
{}
```

В проверенном ответе `data` содержал бренд с `id=8224996`, `timezone="Asia/Vladivostok"` и `networksData.threadsData="nickkem_vl"`. Ответ может находиться внутри текстового JSON в `content`; разбери его перед использованием. Используй данные текущего вызова, а не только этот пример.

## Получить актуальные поля

Аргументы `getAnalyticsAvailableMetrics`:

```json
{"network":"threads","connector":"posts"}
```

Проверенные field ID для коннектора `posts`:

| Field ID | Значение |
| --- | --- |
| THPO02 | Дата и время публикации |
| THPO03 | Текст |
| THPO06 | Ссылка на пост |
| THPO08 | Просмотры |
| THPO09 | Лайки |
| THPO10 | Количество ответов |
| THPO11 | Репосты |
| THPO12 | Цитирования |
| THPO13 | Поделились |
| THPO14 | Вовлечённость в определении Metricool |

Для коннектора `evolution`: `THEV01` — подписчики, `THEV02` — публикации, `THEV03` — изменение числа подписчиков, `THEV05` — взаимодействия, `THEV06` — просмотры постов, `THEV11` — просмотры профиля. Для них отдельно получи текущие описания и правила агрегации; не складывай значения подписчиков по дням.

## Пример запроса постов

Аргументы `getAnalyticsDataByMetrics` для исторической проверки, а не шаблон фиксированного текущего периода:

```json
{
  "brandId": "8224996",
  "from": "2026-11-13T00:00:00+10:00",
  "to": "2026-11-19T23:59:59+10:00",
  "metrics": ["THPO02", "THPO03", "THPO06", "THPO08", "THPO09", "THPO10", "THPO11"]
}
```

Успешный ответ `{"rows":[]}` подтверждает выполнение запроса, но не наличие исторических данных. Если сервис вернул отдельные строки по датам, не принимай служебную дату за ещё один показатель.

## Пример чтения очереди

Аргументы `getScheduledPosts`:

```json
{
  "brandId": "8224996",
  "fromDate": "2026-11-19T00:00:00+10:00",
  "toDate": "2026-11-25T23:59:59+10:00",
  "timezone": "Asia/Vladivostok"
}
```

Замени даты и бренд актуальными значениями. Чтение очереди не публикует сообщения.

## Запись

Планирование и правка доступны через `createScheduledPost` / `updateScheduledPost`, но запись не проверялась тестовой публикацией. Формат внутреннего JSON `info` в этой сессии не был подтверждён. Перед первой записью получи документированный формат; этот файл намеренно не содержит выдуманного payload. Вызов инструмента с произвольной строкой текста вместо правильного `info` не является допустимой проверкой подключения.
