# Каталоги для задач «Мой ассистент»

Подключены три полных снимка рабочих файлов upstream. История Git не скачивалась. Все 104 файла проверены по размеру и Git blob SHA-1; точные деревья и даты — в manifest-файлах рядом.

| Каталог | Когда использовать | Основной файл |
| --- | --- | --- |
| ripienaar/free-for-dev | Хостинг, базы данных, формы, хранение файлов, почта, аналитика | free-for-dev/README.md |
| awesome-selfhosted/awesome-selfhosted | Готовые приложения, автоматизации, CRM, базы знаний | awesome-selfhosted/README.md |
| DigitalPlatDev/FreeDomain | Домены, DNS, HTTPS, публикация и эксплуатация сайтов | FreeDomain/README.md и FreeDomain/documents/ |

## Поиск

Запускай из корня проекта в PowerShell:

```powershell
& ./resources/repositories/Search-Catalogs.ps1 -Query 'hosting' -Catalog cloud -Limit 10
& ./resources/repositories/Search-Catalogs.ps1 -Query 'Activepieces','Baserow' -Catalog selfhosted
& ./resources/repositories/Search-Catalogs.ps1 -Query 'renewal' -Catalog domains
& ./resources/repositories/Search-Catalogs.ps1 -Query 'analytics' -AsJson
```

Поиск локальный, без сети, регистраций и платных API. Запросы ищутся как буквальные подстроки без учёта регистра; несколько запросов объединяются через «или». Используй английские названия и термины. Результат содержит исходный файл, раздел и номер строки. Скрипт предназначен для PowerShell 7.

## Применение к нашим задачам

| Задача | Где искать | Какой результат подготовить |
| --- | --- | --- |
| Опубликовать HTML-доску или мини-страницу | free-for-dev: Web Hosting | Подходящий хостинг, действующие лимиты и способ обновления; при наличии Sites использовать его возможности по задаче |
| Сделать общую CRM с данными на разных устройствах | free-for-dev: BaaS / Managed Data Services; awesome-selfhosted: Baserow | Выбрать хранение и авторизацию; проверить совместную работу и резервные копии |
| Передавать заявки ответственному | awesome-selfhosted: Activepieces | Настроить и проверить конкретный сценарий на тестовой заявке |
| Анализировать посещения страниц | awesome-selfhosted: Umami; free-for-dev: Analytics | Согласовать нужные события, затем проверить сбор на тестовом переходе |
| Собирать опросы аудитории | free-for-dev: Tally; awesome-selfhosted: Formbricks | Проверить ветвления, выгрузку ответов и доступность выбранного тарифа |
| Подключить отдельный адрес к сайту | FreeDomain: FAQ, platform, DNS, operations | Проверить правила регистрации и продления, затем настроить DNS для выбранного сайта |

Это направления выбора, а не уже установленные сервисы. Условия бесплатных тарифов из каталога перед внедрением перепроверяются у поставщика. Наличие приложения в каталоге не означает бесплатный сервер или бесплатные API моделей.

## Обновление снимков

Снимки оставлены без изменений; наша инструкция и поиск находятся вне upstream-каталогов. Для обновления получи новое полное дерево через GitHub, загрузи файлы в отдельный каталог, проверь размер и Git blob SHA-1 каждого файла, сравни версии, затем обнови снимок и manifest. При доступном Git можно вместо этого сделать отдельный shallow clone в новый каталог. Встроенные скрипты upstream автоматически не запускаются.

Корневой AGENTS.md закрепляет использование этих каталогов в задачах данного рабочего проекта. Для других окружений нужен доступ к этим файлам или архиву.
